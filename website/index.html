    Ask Stoguard
    Scan-grounded mentor with Problem→Fix→Learn More cards — optional local Ollama rewrite.
    
        
    Predictive AI
    GB/day curves for Docker, Ollama, Hugging Face, DerivedData, Downloads, Time Machine — plus days-to-full.
    
        
    Health Score
    Storage · Performance · Environment · Security · AI Workspace — daily / weekly / monthly history.
    
        
    Background Watch
    While the app is open: growth spikes, build-cache jumps, idle models — with notifications.
    
        
    AI Workspace
    Model sizes, last used, quants, RAM estimate, GPU best-effort, duplicates, archive or Trash.
    
        
    Env Doctor
    Brew doctor, Node/Python conflicts, Java, Android SDKs, Flutter dupes, Rust, asdf/mise.
    
        
    Repo Doctor
    Heavy folders, dead deps, binaries, build artifacts — and a secrets scanner.
    
        
    Explain Everything
    Why? What happens? Can I undo? What rebuilds? Is this common? — on every recommendation.
    
        
    Plugin SDK
    Detection + explanation + risk + safe actions + docs links — community JSON packs.
    
        
    Learning Center
    Teachable glossary: DerivedData, Docker, npm, Ollama — when to delete and what happens after.
    
        
    Automation
    Daily scan, Sunday safe tidy, npm>5GB — stages cleanup for your confirm (never silent delete).
    
        
    Duplicates
    Fingerprint-confirmed only; related Node/Python/Rust installs show differences, not false dupes.
    
        
    Media Optimizer
    Large images/videos/docs — approve keep-resolution optimize or a KB/MB/GB/TB target.
    
        
    Smart Cleanup
    Trash-only with safety labels, Keep memory, and confirmations every time.
