Stoguard Download

Privacy

Stoguard is built to run on your machine.

What stays local

  • Scan results, sizes, and safety labels
  • Cleanup history and adaptive scan profile
  • Optional continuous monitoring samples
  • Fleet JSON exports you choose to create

Network

Cloud rules refresh is optional and only runs if you configure a rules feed URL. By default the app uses bundled rules. No analytics or ad SDKs.

Permissions

Full Disk Access is required to measure developer caches under Library and related paths.
